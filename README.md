# Z·SWITCH (zcode-switch)

**简体中文** ｜ [English](README.en.md)

Tauri 2 桌面工具：在多个 ZCode 账号之间一键切换，自动显示额度。只换登录身份——项目、会话、设置全部共用不动。

![screenshot](docs/screenshot.png)

## 功能

- **保存 / 切换账号**：一键切换登录身份；切换前自动保全当前登录，绝不丢号；设备身份跟账号走，远程控制中继密钥跨切换保活；热切换会同步对齐 provider 家族与 builtin apiKey（跨站点 z.ai ↔ BigModel 切换后无需在客户端手动刷新）
- **添加账号**：OAuth 登录新号（BigModel / z.ai 双入口），可选**系统默认浏览器**或**应用内窗口**（输邮箱密码 / 扫码），全程不动当前登录
- **额度展示**：账号行内联显示套餐额度与重置时间，多套餐分组；可一键刷新全部账号额度（顺带每 10 分钟刷新一次领取资格）
- **账号分组与检索**：可给账号打自定义分组标签；列表支持平铺 / 分组（默认按**额度健康度**归类：充足 / 紧张 / 耗尽 / 需重新登录 / 查询失败 / 待查询）、搜索、筛选、排序与紧凑 / 详细密度，支持批量分组与批量删除，并可一键隐藏账号信息（便于截图 / 演示）
- **活动领取**：可领套餐一键领取；「自动领取」开关（默认关）定时自动检测并领取，手动操作优先
- **低额度自动切换**：当前账号剩余额度低于阈值（默认 15%，可调）时，自动切到额度最多的账号；工具栏一键开关，ZCode 运行中配合「热切换」使用；可**指定关注模型**（如 GLM-5.3-Flash），只按该模型的额度判定与选号。判定是**双触发**的：剩余百分比越线 **或** 按真实消耗速率算出的**剩余时间(ETA) ≤ 安全余量**（预测式，能在烧干前几分钟动手）；数据过期会先刷新再判，切换前会对候选做一次预校验，没有达标账号时降级切「还有额度的最好账号」而不放弃；每次决策都进后端审计日志（事件原因/目标/耗时/前后余量）
- **秒级额度信号（免轮询）**：自动切换优先读取 ZCode 客户端自己写在 `~/.zcode/v2/logs/` 里的额度快照（每个额度池的精确 token 余量、客户端自己的「计划可用」判定、当前请求用的模型），**零额外网络请求、不等风控**；读不到时自动回落到官方接口轮询，设置里会显示当前用的是哪个信号源与数据年龄
- **全局设置在工具栏弹窗里**：点工具栏齿轮就地配置（自动化 / 行为 / 授权 / 账号库 / 语言 / ZCode 路径），不再弹独立窗口；关注模型可直接从**已读到的模型**里选，也可以手动输入
- **加密导入导出**：`.zsb` 捆绑包，PBKDF2(100k) + AES-256-GCM 口令加密
- **中英双语**：设置里一键切换 中文 / English，主窗、托盘、错误提示、CLI 输出全覆盖；首次运行按系统语言自动选择
- **托盘 / 开机自启 / CLI 自动化**

## 安全设计

- **本地优先**：所有数据在本地，无遥测、无远端存储；额度查询直连官方接口
- **WebView CSP**：`script-src` 基线为 `'self'`；为官方活动的网页组件放行了最小范围的第三方脚本与图片来源，界面事件不依赖动态执行、走白名单式分发
- **防丢号**：切换前自动保全未入库登录；文件写入走临时文件 + 原子 rename
- **路径穿越防护**：账号 id 白名单（`[A-Za-z0-9-]`），删除/读取均不可逃出账号库目录
- **加密导出**：PBKDF2-HMAC-SHA256（100k 迭代）+ AES-256-GCM，随机 salt/nonce；错密码即失败，无明文痕迹
- **凭据只在本地解密**：凭据解密仅用于显示用户名/邮箱；导出文件凭口令加密

## CLI

```
zcode-switch.exe --cli state|list
zcode-switch.exe --cli quota [--id <账号id>]
zcode-switch.exe --cli claim-preview [--id <账号id>]
zcode-switch.exe --cli capture [--name 名称]
zcode-switch.exe --cli switch --id <id> [--force] [--restart|--no-restart] [--hot <bool>|--no-hot]
zcode-switch.exe --cli kill
zcode-switch.exe --cli export --id <id> --out <a.zsb>
zcode-switch.exe --cli export-all --out <all.zsb>
zcode-switch.exe --cli import --file <file.zsb>
zcode-switch.exe --cli rename|delete|update|behavior|setpath|launch
zcode-switch.exe --cli --lang en state              # 英文输出（--lang 空格传值、可置于任意位置；默认跟 GUI 语言/系统语言）
```

CLI 密码（export / import）：优先环境变量 `ZSW_PASSWORD`（不出现在进程列表和命令历史），也可 `--password <密码>`。

## 常见问题

### 添加账号的登录窗口长时间黑屏 / 没内容？

登录页需要从网络加载官方页面（z.ai 在部分网络下较慢，需要海外出口）。窗口会先显示「正在打开登录页…」占位，不会再是纯黑屏；若长时间无响应，请在「设置 → 授权登录」里给登录窗口配置代理，或改用「系统默认浏览器」登录。

### macOS 弹出「麦克风 / 辅助功能 / 录屏」权限询问？

全部拒绝即可，不影响任何功能。
应用内嵌的登录等网页由系统 WebView 渲染，网页发起的请求会被透传为应用的系统权限询问；应用本体与其内嵌网页均未使用这三项能力。

### 自动切换为什么不灵敏 / 用到额度了还没切？

先看「设置 → 自动化」里自动切换下方的诊断行，它直接告诉你三件事：

- **信号源**：写着「客户端日志（Ns 前）」说明走的是秒级本地信号；写着「官方接口轮询」说明没找到客户端日志（ZCode 未启动过 / 日志目录异常），已自动回落到轮询。
- **剩余时间（ETA）**：按真实消耗速率算出来的时间，比百分比直观——小额度池 15% 可能只有一分钟，大额度池 15% 可能还有一小时。
- **最近一次决策**：如 `switch` / `blocked-need-hot` / `preflight-fail`，每次都同时写进后端日志（`%LOCALAPPDATA%/…/logs/oauth.log`，`[auto-sw]` 行），调参有据可依。

仍不灵敏时按顺序查：

1. **ZCode 正在跑但没开「热切换」**：自动切换不会强杀客户端，会直接提示（`blocked-need-hot`）。开热切换即可。
2. **关注模型填错了**：判定只看这个模型。留空时会自动跟随客户端**实际在用**的模型（日志里的 modelId），但显式填对更稳。
3. **一直显示「官方接口轮询」**：说明客户端日志没读到。先启动一次 ZCode 产生日志；日志目录非默认位置时暂时只能靠轮询。
4. **风控导致的陈旧数据**：接口 429/3012 被限流时不会拿旧数据当依据，而是先刷新（`as.noteStale`）；如果持续刷新失败，把阈值设大一些留出余地。

### 提醒：自动领取会占用额度查询，但不再阻塞切换

自动领取（`auto_claim`）与全库刷新（工具栏「刷新」）会排队使用额度接口；自动切换在其间**依然会决策并执行**（用最近一次可信样本 + 客户端日志），但新样本的获取会等它们让出。
